# 🚀 JavaScript Practice Projects

Welcome to my JavaScript learning repository! This project contains a collection of **12 different practice problems** and programming assignments that I solved while mastering core JavaScript logic, arithmetic operators, and user input handling.

---

## 🛠️ What is Included?
This repository contains solutions to **12 programming questions**, including:
- **Variable Constraints & Rules:** Practicing correct naming rules (avoiding numbers at the start, hyphens `-`, and reserved words like `class`).
- **Data Types Practice:** Understanding `typeof` operator, `null`, and `undefined`.
- **Advanced Calculations:** Accurate Age Calculator using Birth Year, Discount Value Calculator, and Currency Converter using exchange rates.
- **BODMAS & Operator Precedence:** Deep dive into how JavaScript executes Multiplication (`*`), Division (`/`), and Modulus (`%`) from Left to Right.

---

## 💻 How to Run

1. Make sure you have **Node.js** installed on your computer.
2. Open your terminal or VS Code terminal in this project directory.
3. Run any of the 12 files using the following command:
   ```bash
   node filename.js
   ```
